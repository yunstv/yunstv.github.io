02

五条铁律：贯穿全程的约束条件

这五条不属于任何单一阶段，而是所有决策的前置过滤器。任何具体动作和它们冲突，都以它们为准。

原则 ①

出面原则

你本人不出面跑货源/工厂，由嫂子或堂弟出面。公司品牌独立注册即可，不需要过度隐身。

  • 你在卖伞布，不出现在伞厂面前就没有暴露问题
  • 唯一注意：尽量避开你自己的布料客户工厂 —— 不是不能，是省事
原则 ②

先跑通再招人

任何岗位先自己干出 SOP 再招人，不提前配齐团队。

  • 没有 SOP 别招人 —— 招来也带不动
  • 人力成本红线：月人力 ≤ 月毛利 40%
原则 ③

资金纪律

紧急备用金 15~20万雷打不动，不跑通不囤货。

  • 旺季前 1~2 个月才集中备货
  • 每笔广告费都要复盘 ROI
  • 货款占用 ≤ 总资金 30%（≈18万滚动）
原则 ④

亲戚协议先行

股权/工资/分红/退出/决策权白纸黑字，丑话说在前面。

  • 干活拿工资、出钱拿分红，两笔账分开
  • 协议花 2000 块律师费，比以后伤感情便宜得多
原则 ⑤

发货合规

前期店面自营（电子面单 + 48 小时），日单 200+ 再评估云仓。

  • 红线：不跨平台转单、不虚假发货、不用非电子面单的「无货源」模式

附加设定 · 两个弹性开关

嫂子不辞职方案

跑通期远程管店，报酬写死为「不给或象征性补贴 2000/月」；满足触发条件后再全职，全职按店长市场价 6000~8000 + 提成。

品类弹性

公司不局限于雨伞 —— 淡季卖拖鞋/雨衣/百货平滑现金流。所以公司名不带「伞」字、经营范围一次写全。

纪律 ①

备用金雷打不动

15~20 万只用于旺季备货、突发支出、试错成本 —— 任何时候不动。

纪律 ②

不跑通不囤货

前期只备爆款小批量。货款占用 ≤ 总资金 30%（≈18 万滚动）。

纪律 ③

旺季前才集中备货

雨季前 1~2 个月，按去年同季 × 1.5 预估。雨具压货 = 压现金流。

纪律 ④

每笔广告费复盘 ROI

前 3 个月约 2~3 万/月，ROI≥1.5 为红线，每款单独记账。

月固定成本 → 保本单量

保本单量 = 月固定成本（房租 + 工资 + 杂费）÷ 单均毛利　　// 低于保本单量，就是在亏
  • 房租按封顶 6000/月估；嫂子全职前按「不给或象征性 2000/月」，全职后 6000~8000 + 提成
  • 这个数字要每月重算一次，因为招人后固定成本会跳台阶 —— 招一个人就等于抬高一次保本线

五份协议：把丑话说在前面

协议 ①工资制

嫂子全职后按 6000。干活拿工资、出钱拿分红，两笔账分开。

协议 ②决策权

日常由嫂子+你拍板；重大事项需 ≥2/3 股权同意。

协议 ③分红

每季度或半年一次，利润留存 30% 做发展资金。让姐姐堂弟清楚钱什么时候能回。

协议 ④退出

2 年内不得退股；退出按净资产或协商价 —— 防止旺季前有人撤资。

协议 ⑤财务透明

每月给 3 位股东发报表（收入/支出/库存/利润）—— 安抚不干活股东的唯一方式。

身份隔离：只做低成本动作

值得做（成本≈0）

  • 你本人不出面跑货源/工厂，嫂子或堂弟去
  • 公司名/品牌与布料生意无关联，工商信息、店铺名分开
  • 别用布料公司关联手机号注册平台账号
  • 进货尽量避开你自己的布料客户工厂 —— 不是不能，是省事

不值得做（过度隐身）

  • 别为「隐身」花额外成本 —— 嫂子/堂弟正常跑工厂、询价、谈价即可
  • 合规红线跟隐身无关，必须守：电子面单 / 48h 发货 / 物流轨迹真实
  • 红线三不：不跨平台转单、不虚假发货、不用非电子面单的「无货源」模式
07

成本核算：把你的信息差变成议价权

这是整份规划里最有独特价值的一节。别人拿到报价只能猜贵不贵，你能自下而上算出这把伞该值多少钱，然后拿这个数字当标尺去砍价。

成本拆解树

一把成品伞
① 伞面布 你最准
用布量(㎡) × 布价 + 损耗 5%　—— 其他卖家算不了这么精，这就是你的优势
② 伞骨 成本大头
铁骨 / 玻纤骨 / 碳纤骨，按规格或按把报；决定伞的档次，多询几家
③ 配件
伞柄（塑料/木/弯钩）、伞珠、伞帽、开关弹簧 —— 1688 搜「伞配件」批量价可谈
④ 人工加工费
缝伞面 / 装骨 / 包装分开问；问「不带料的加工费」，摸清上虞崧厦当地行情
⑤ 包装 隐形利润杀手
伞套 + 吊牌 + 快递袋 + 气泡膜，单把 0.3~1 元，别漏算
⑥ 损耗
统一按 5% 计入
成本价 = 面料 + 伞骨 + 配件 + 人工 + 包装 + 损耗(5%)
目标出厂价参考 = 完全成本 × (1 + 15~25%)

※ 直杆 / 折叠 / 自动三种款式零部件不同，必须按款分别算。

比价判断决策树

拿着你算出的成本价去要报价
1688 / 本地工厂，由嫂子或堂弟出面
计算差价
差价率 = (厂家报价 − 你的成本推算) ÷ 你的成本推算

< 0%

平台开店10 步流水线

前期集中 1 个平台跑通，别贪多。新手优先拼多多（门槛低、流量大、适合低客单），淘宝搜索流量稳，抖音需要做视频。

基础即可（banner/分类/详情模板），重点钱花在主图

平台避坑 5 条

  • 别信「代运营」 —— 前期自己干，代运营水太深
  • 别买「刷单」 —— 封店风险
  • 保证金别一次交多店
  • 开店后 7 天内必须上架商品，长期空店会被清退
  • 客服响应率是权重指标：拼多多 3 分钟、淘宝 5 分钟 —— 嫂子要盯住

  • 公司名：以商贸/电子商务/供应链结尾，不带「伞」字 —— 为淡季卖拖鞋/雨衣/百货留路；注册前搜重名
  • 品牌名：中文 + 英文，大众化易记，备 3 个防被占用；别和布料公司同名相似
  • 商标：第 20 类（家具/伞具）必注，第 25 类（服装鞋帽）建议注册，500~1000 元/类
  • 店铺名：与品牌一致，可加类目词（如「XX旗舰店」），也先想好 3 个备选
  • 经营范围一次写全：雨伞/雨衣/鞋帽/日用品/家用百货/互联网销售 —— 写全了以后加品不用改执照

物流：四点谈判与发货 SOP

低客单类目里，快递费是最大成本之一。散客价 8~12 元、电商协议价 3~5 元 —— 这中间的差价直接决定你有没有毛利。

谈判点 ①价格

首重 1kg 内目标 3~5 元/单；谈全国均价而非分区价。报价时先报量「月发 3000 单」。

谈判点 ②账期

谈月结（月底对账付款），别现结 —— 月结省现金流，现结没有任何优势。

谈判点 ③服务

电子面单支持、上门揽收时间、超重续重价、偏远地区加价（新疆/西藏/内蒙/青海）提前问清，否则亏运费。

谈判点 ④赔付

丢件/破损赔付标准、时效承诺、异常件处理流程 —— 赔付标准写进合同，高价值件考虑保价。

快递谈判话术（多家报价互相压价）

「我这边电商月发货量稳定增长，现在月发 3~5 千单，想谈协议价，全国均价 4 块以内能做吗？电子面单能开通吗？可以月结吗？」

  • 旺季（雨季前）快递会涨价 → 提前 1~2 个月锁定价格，合同写明旺季价格上浮上限
  • 进货物流单独谈：工厂→店面的货走普通货运/物流（大件走物流、小件走快递），和发货快递分开
  • 至少签 2~3 家：主用 1 家 + 备用 1~2 家，防一家涨价/爆仓/停运时被动

发货 SOP：六步 + 两条硬约束

备货公式与库存循环

铁律一句话：爆款备货、非爆款不备。只给 S/A 级备货，其他款一件代发或小批量。

备货量 = 日均单量 × 补货周期天数 × 1.5 安全系数 − （在途库存 + 在手库存）
备货决策约束： 预估销量 × 进价 ≤ 该款可承受的资金占用　// 超了就分批备
现金流上限： 货款占用 ≤ 总资金 30%　（60万 → 18 万以内滚动）

补货周期怎么定

  • 补货周期 = 下单到到货的天数
  • 本地厂（上虞）补货快 → 小批量高频补
  • 外地厂提前 1~2 周下单
  • 跟供应商约定补货响应时间

安全库存 & 周转

  • 至少留 3~5 天的量兜底 —— 断货 = 权重掉 + 差评，得不偿失
  • 整体库存周转目标：30 天内卖完（月周转 1 次）
  • 周转慢的款就是资金黑洞

旺季备货

  • 雨季前 1~2 个月集中备货
  • 按去年同季行情 × 1.5 预估
  • 旺季断货比压货更亏 —— 这是唯一允许放大备货的窗口

毛利拆解与成本优化顺序

优化顺序有讲究：先压最大头（进货价 / 快递），再抠小项（包装 / 耗材）。但有一条不许碰 —— 别为了省成本牺牲品质，雨伞退货率高是致命的。

单款毛利 = 售价 − 进货价 − 快递费 − 广告费 − 包装 − 平台扣点　// 六项都要减，每款单独算
保本单量 = 月固定成本（房租 + 工资 + 杂费）÷ 单均毛利　// 低于它就是在亏
大头 · 优先 ① 压进货价

销量稳定后谈阶梯价：月采 3000 把降 5%~10%。有量才有议价权，多供应商比价。

大头 · 优先 ② 压快递价

月发量上来后再谈一次，或启用第 2 家压价。快递费是低客单最大成本之一。

中项 ③ 广告优化

保留 ROI 高的词/人群，砍掉烧钱词，降低 CPC。测款期学会怎么投，现在学怎么省。

小项 ④ 包装优化

找更便宜但达标的包装，批量采购。单把省 0.2 元，月销 3000 就省 600。

增收 ⑤ 定价测试

爆款小幅涨价 +1~2 元测转化是否掉，掉就回调。客单价低，1 元差价就是利润。

别漏算 ⑥ 平台扣点

月度毛利报表

成长期：两条扩张轴

横向是平台，纵向是品类与供应链。两条轴都有明确的边界条件 —— 多平台的代价是管理复杂度翻倍，品类扩展的边界是不能离开「小件百货」。

轴 A · 多平台扩展（横向）

开新平台的条件

满足

新平台前 3 个月都是学习期
  • 商品同步：多平台用同一套商品库（ERP 同步），库存统一管理 —— 库存不同步是最大的坑（超卖）
  • 定价差异：拼多多走量价低、淘宝稍高；差异化定价前先查平台价格规则
  • 视觉复用：主图/详情一套资产，按平台规范微调尺寸，别每个平台重做一遍
  • 团队分工：每平台 1 个「店长」（运营助理升级），嫂子 = 总店长管协调，你管策略 + 供应链
  • 预算分配：按平台 ROI 分配 —— 谁赚钱给谁多，每周复盘动态调整
  • 三个坑：① 别同时上新平台（人力跟不上）② 别用同一批货超卖 ③ 各平台规则不同（发货时效/客服响应）

轴 B · 品类与供应链（纵向）

品类扩展：围绕「雨具 + 居家小百货」
拖鞋 / 雨衣 / 雨鞋 / 收纳 / 防晒用品 —— 优先能复用供应链和客户群的品类。边界：别离开「小件百货」太远，物流、打包、客群都要复用
淡季补位：秋冬主推拖鞋/雨衣/百货
平滑现金流。公司注册时经营范围已写全，直接上品不用改执照 —— 这就是准备期埋的伏笔
品类测试：新品沿用测款打法
小预算测、数据说话。别盲目铺品，铺得多死得快

供应链三级升级

SC1直连工厂

SC2独家/定制款

SC3框架协议

按季度签采购框架，锁价锁量 —— 旺季有货、淡季不压

你的护城河

你懂面料成本 —— 直连工厂后你的进货价就是同行羡慕的。这条护城河是准备期成本核算表的复利收益。

专职投手

广告投放量大了就招（底薪 + 提成），按 ROI 考核，投得好给高提成。

品牌化动作

注册商标后做包装升级 / 吊牌 / 卡片，积累品牌认知。品牌是长期资产，低客单类目靠复购。

私域与复购

包裹放卡片引导关注/进群 —— 拖鞋/雨衣复购率高。私域是低成本复购渠道，成长期开始做。
