<Callout type="info">
  互联网的进化不是技术堆砌的产物，而是**一连串约束被打破**的过程：物理距离、协议割裂、终端门槛、内容生产权、信任成本。看清这条主线，今天的 AI 和 Web3 就不会显得突兀。
</Callout>

## TL;DR

| 阶段 | 时间 | 标志性事件 | 解决的核心约束 |
|---|---|---|---|
| 前夜 | 1960s | 包交换理论 | 通讯线路被占用即中断 |
| ARPANET | 1969 | 第一次跨主机登录 | 异构主机之间无法对话 |
| 互联网雏形 | 1983 | TCP/IP 全面切换 | 多种网络无法互联 |
| WWW | 1991 | 首个网页发布 | 文档无法跨机超链接 |
| Web 1.0 | 1995–2003 | 浏览器大战、门户网站 | 普通人难以"上网" |
| Web 2.0 | 2004–2010 | 社交、UGC、AJAX | 用户只能"读"不能"写" |
| 移动互联网 | 2007–2015 | iPhone、4G、App Store | 上网要坐在桌前 |
| 云与平台 | 2010– | AWS、抖音、超级 App | 个人/团队无力运维基础设施 |
| AI + Web3 | 2020– | LLM、智能体、链上身份 | 信息生产成本与平台中心化 |

## 1. 前夜：包交换的思想实验（1960s）

在 ARPANET 之前，全球的电话和电报都是**电路交换（circuit switching）**——
拨号双方独占一条物理链路，一断就全断。冷战阴影下，美国国防部高级研究计划局
(ARPA) 想要一个"被核打掉几个节点也不会瘫痪"的通讯网络。

1961 年，MIT 的 Leonard Kleinrock 把通讯的数学基础建立起来；1964 年，
Paul Baran 在 RAND 写出 _On Distributed Communications_，提出**分组交换
(packet switching)** ——把消息切成小包，每个包独立寻路。

<Callout type="info">
  分组交换看似只是工程细节，但它让"网络的可靠性"从"链路本身"
  迁移到"协议层重传"——这是后来所有协议层级化设计的源头。
</Callout>

## 2. ARPANET：四个节点的"互联网"（1969）

1969 年 10 月 29 日，加州大学洛杉矶分校（UCLA）的研究生 Charley Kline
向斯坦福研究所（SRI）尝试登录，敲入 `LOGIN`，刚打到 `LO` 系统就崩了——
这是**人类第一次跨主机通讯**。当年年底，UCLA / SRI / UCSB / Utah
四个节点联了起来。

ARPANET 用的不是 TCP/IP，而是更早的 NCP（Network Control Protocol）。
但它已经具备了今天互联网的雏形：

- 异构主机之间能互发数据
- 数据走包交换
- 路径由路由器（当时叫 IMP）动态决定

## 3. TCP/IP：让"网络的网络"成为可能（1973–1983）

ARPANET 解决了"一组主机相连"，没解决"多种网络相连"——
军用网、卫星网、Ethernet 各说各的协议。

Vinton Cerf 和 Robert Kahn 在 1974 年发表 _A Protocol for Packet Network
Intercommunication_，提出 **TCP/IP 双层模型**：

- **IP** 负责寻址和路由，不保证送达
- **TCP** 负责可靠传输（重传、排序、流控）

```text
应用层  HTTP / SMTP / DNS / SSH …
传输层  TCP / UDP
网络层  IP
链路层  Ethernet / Wi-Fi / 4G / 5G
物理层  电缆 / 光纤 / 无线电波
```

1983 年 1 月 1 日，ARPANET 全面切换到 TCP/IP——这一天通常被视作
**"互联网"作为概念的正式生日**。从此任何一种链路只要跑得起 IP，
就接入了同一张全球网。

<Callout type="success">
  TCP/IP 的天才之处在于**分层 + 端到端**：核心网络保持简单（只负责转发），
  复杂逻辑放在两端的主机。这条原则后来被概括为 **"哑管道，聪明端点"**，
  也是为什么互联网比电信网更适合创新——你不需要运营商批准就能在端点跑新协议。
</Callout>

## 4. WWW：让文档可以互相引用（1989–1993）

1989 年，欧洲核子研究中心（CERN）的英国工程师 Tim Berners-Lee 写下提案
_Information Management: A Proposal_。他想解决的问题很朴素：
**实验室里几千份内部文档，没法互相超链接**。

他提出三个东西，一直用到今天：

- **URL**：给每份文档一个全球唯一地址
- **HTTP**：用最简单的请求/响应取这份文档
- **HTML**：在文档里嵌入指向其他文档的链接

1991 年 8 月 6 日，第一个公开网页 [info.cern.ch](https://info.cern.ch/) 上线。
1993 年 NCSA Mosaic 浏览器发布，**图片可以和文字一起出现**——
WWW 从此进入大众视野。

<Callout type="info">
  互联网 ≠ WWW。互联网是底层网络（TCP/IP 之上跑的一切），
  WWW 只是其中**一种应用**——和 email、FTP、IRC 平级。
  只是它太成功，以至于今天很多人把两者混为一谈。
</Callout>

## 5. Web 1.0：静态门户与第一次泡沫（1995–2003）

这个阶段的关键词：**只读、门户、目录**。

- 网页大多是纯静态 HTML，由站长手写或后台批处理生成
- Yahoo!、Sina、Sohu 这样的"门户"靠人工编目导航
- 商业模式还在摸索，但**广告 + 邮箱**已经跑通
- 1995 网景上市点燃 dot-com 泡沫，2000 年 NASDAQ 崩盘把它打回原形

技术上的关键解锁：

| 年份 | 技术 | 影响 |
|---|---|---|
| 1995 | JavaScript | 网页里第一次能跑脚本 |
| 1995 | SSL | 浏览器和服务器之间能加密 |
| 1996 | CSS | 内容与样式开始分离 |
| 1998 | Google PageRank | 链接成为信息检索的"民主投票" |
| 2003 | WordPress | **不写代码就能发博客** |

WordPress 标志着内容生产权第一次开始从"懂 HTML 的人"下放到普通用户。

## 6. Web 2.0：用户从读者变成作者（2004–2010）

Tim O'Reilly 在 2004 年提出 **Web 2.0** 这个词，核心特征：

- **用户生成内容（UGC）**：MySpace、Flickr、YouTube、Facebook、Twitter
- **AJAX**：网页不再整页刷新，开始像桌面应用
- **API 经济**：Twitter、Google Maps 开放 API，催生第三方生态
- **网络效应**：用户越多越好用（社交、点评、问答）

技术栈也彻底换血：

```text
1995  CGI + Perl + Apache + 静态 HTML
2005  LAMP + AJAX + jQuery
2010  RESTful API + JSON + 单页应用（SPA）
```

<Callout type="warning">
  Web 2.0 同时埋下了今天最尖锐的矛盾：**用户生产内容，平台拥有数据**。
  这个不对等是 2020 年代 Web3 想破解的核心命题，也是 GDPR、反垄断、
  数据主权讨论的根源。
</Callout>

## 7. 移动互联网：把网放进每个人的口袋（2007–2015）

2007 年 1 月 9 日，乔布斯发布 iPhone。一年后 App Store 上线，
2009 年 4G 商用，移动互联网的三件套齐了：

- **触屏智能手机**：交互范式从"键盘+鼠标"变成"手指"
- **应用分发市场**：开发者不需要谈渠道就能触达全球用户
- **高带宽蜂窝网络**：上网不再受限于办公室和咖啡厅 Wi-Fi

中国在这一波里完成弯道超车：

- 2011 微信发布，半年破亿用户
- 2013 余额宝把支付宝从工具变成金融平台
- 2014 滴滴 vs 快的，"补贴大战"教育市场
- 2016 抖音上线，**算法推荐**第一次大规模碾压人工编辑

到 2018 年左右，全球**移动互联网用户数超过 PC 互联网用户数**——
"互联网" 在大多数人的体感里第一次不再以 PC 为中心。

## 8. 云与平台：基础设施的工业化（2006–今）

2006 年 AWS 推出 EC2 / S3，**计算和存储变成按秒计费的水电**。
后果是双向的：

- **正向**：两个工程师在车库里能跑出 Instagram；初创公司不再为机房融资
- **负向**：基础设施越来越集中在三五个超大型云厂商，**单点故障会让半个互联网下线**

同时，"超级 App + 内容平台" 模式吃掉了开放网络：

| 旧 Web | 新平台 |
|---|---|
| 个人博客 | 公众号、小红书 |
| RSS 订阅 | 算法推荐流 |
| 邮件列表 | Discord / 群聊 |
| 开放论坛 | 知乎、Reddit |
| 个人域名 | Linktree / X handle |

Tim Berners-Lee 后来在多场演讲里承认：他设计的"任何人都能发布"的开放网，
正在被几家平台的算法重新围墙化。这种**再封闭化（re-centralization）**
是 Web3 叙事的直接起因。

## 9. 这一代的两个变量：AI 与 Web3（2020–）

2022 年 11 月 ChatGPT 上线后两个月用户破亿，是互联网历史上最快达到这一规模的产品。
它带来的不是新的"上网方式"，而是**信息生产成本的塌缩**——
任何人都能瞬间得到一篇过得去的文章、一段能跑的代码、一份基础的设计稿。

与此同时，Web3 的探索没有停：

- **比特币 / 以太坊** 把"信任"从中介机构搬到链上
- **钱包** 第一次让个人可以拥有跨平台、不可被注销的数字身份
- **NFT、链上社交** 实验"我的内容真的归我"

但 Web3 还没解决它最重要的问题：**普通用户为什么要用它？**
私钥管理太硬核、Gas 费太贵、UX 不如 Web2。
关于这点我会在 [Web3 是什么，能替代 Web2 吗？](/blog/web3-vs-web2) 里详细拆。

## 10. 一条主线：约束如何被一次次打破

如果只能用一句话概括六十年：

> **互联网每一次跃迁，都是某个"上一代认为理所当然"的约束被打破。**

- 包交换打破了 **"通讯必须独占链路"**
- TCP/IP 打破了 **"不同网络无法互联"**
- WWW 打破了 **"文档无法跨机器引用"**
- WordPress 打破了 **"发布内容必须懂 HTML"**
- iPhone 打破了 **"上网必须坐在电脑前"**
- 云打破了 **"创业必须先建机房"**
- LLM 正在打破 **"高质量内容必须由专业人士生产"**
- Web3 想打破 **"数字身份和资产必须托管在平台手里"**

<Callout type="success">
  当你在评估"下一波风口"时，比起追逐流行词，更有效的问法是：
  **"今天哪个被默认接受的约束，再过五年回头看会显得很荒谬？"**
  AI 工程师、机器人、脑机接口、能源-算力一体化——
  每个看似分散的赛道，都能从这个角度找回主线。
</Callout>
